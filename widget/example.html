🤖 NexusAI Widget Demo

This page demonstrates the embedded NexusAI chat widget. Look for the chat bubble in the bottom-right corner!

📝 Instructions:
  1. Create a project in the NexusAI Dashboard
  2. Copy your API key from the project settings
  3. Replace YOUR_API_KEY below with your actual key
  4. Upload some documents to train your AI
  5. Click the chat bubble to start chatting!

🔧 How to Integrate

Add this single line before your closing </body> tag:

<script 
  src="http://localhost:8000/widget.js"
  data-project-key="YOUR_API_KEY"
  data-api-url="http://localhost:8000"
></script>

⚙️ Configuration Options

Attribute Description
data-project-key Your API key (required)
data-api-url Backend API URL
data-position "bottom-right" or "bottom-left"
data-primary-color Theme color (hex, e.g. "#6366f1")
