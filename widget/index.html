NexusAI Widget Test

This page demonstrates the NexusAI chat widget integration.

Integration Code

<script 
  src="widget.js" 
  data-project-key="your-api-key"
  data-api-url="http://localhost:8000"
  data-title="Support Chat"
  data-primary-color="#3b82f6"
></script>

Available Options

  • data-project-key - Required. Your project API key
  • data-api-url - Optional. API endpoint (default: https://api.nexusai.com)
  • data-position - Optional. "bottom-right" or "bottom-left"
  • data-primary-color - Optional. Hex color for branding
  • data-title - Optional. Chat window title
